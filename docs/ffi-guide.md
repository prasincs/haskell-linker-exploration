# Haskell Foreign Function Interface (FFI): Complete Guide

## Overview

The Foreign Function Interface (FFI) allows Haskell programs to interoperate with code written in other languages (primarily C). This is essential for:

- Calling existing C libraries
- Interfacing with operating system APIs
- Embedding Haskell in other applications
- Performance-critical operations

This guide covers both directions: **calling C from Haskell** and **calling Haskell from C**.

## Calling C from Haskell

### Basic Example

**C Code** (`math_ops.h`):
```c
#ifndef MATH_OPS_H
#define MATH_OPS_H

int add(int a, int b);
double square_root(double x);

#endif
```

**C Implementation** (`math_ops.c`):
```c
#include "math_ops.h"
#include <math.h>

int add(int a, int b) {
    return a + b;
}

double square_root(double x) {
    return sqrt(x);
}
```

**Haskell FFI** (`MathOps.hs`):
```haskell
{-# LANGUAGE ForeignFunctionInterface #-}

module MathOps where

import Foreign.C.Types

-- Import a C function
foreign import ccall "math_ops.h add"
    c_add :: CInt -> CInt -> CInt

-- Import with safe/unsafe annotation
foreign import ccall unsafe "math_ops.h square_root"
    c_sqrt :: CDouble -> CDouble

-- Haskell wrappers with natural types
add :: Int -> Int -> Int
add x y = fromIntegral $ c_add (fromIntegral x) (fromIntegral y)

squareRoot :: Double -> Double
squareRoot x = realToFrac $ c_sqrt (realToFrac x)
```

**Compilation**:
```bash
# Compile C code
gcc -c math_ops.c -o math_ops.o

# Compile Haskell code
ghc -c MathOps.hs

# Link together
ghc MathOps.o math_ops.o -o program
```

### Standard Library Functions

You can import C standard library functions directly:

```haskell
{-# LANGUAGE ForeignFunctionInterface #-}

import Foreign.C.Types
import Foreign.C.String

-- Math functions
foreign import ccall "math.h sin"
    c_sin :: CDouble -> CDouble

foreign import ccall "math.h cos"
    c_cos :: CDouble -> CDouble

-- String functions
foreign import ccall "string.h strlen"
    c_strlen :: CString -> IO CSize

-- System calls
foreign import ccall "unistd.h sleep"
    c_sleep :: CUInt -> IO CUInt

-- Example usage
main :: IO ()
main = do
    print $ c_sin 1.0  -- Calls C's sin() function
    c_sleep 1          -- Calls C's sleep() function
```

**Note**: You don't need to link explicitly with `-lm` for math functions; GHC adds it automatically.

## Calling Haskell from C

This is more complex because Haskell code needs the Runtime System (RTS) to execute.

### Complete Example

**Haskell Library** (`Fibonacci.hs`):
```haskell
{-# LANGUAGE ForeignFunctionInterface #-}

module Fibonacci where

import Foreign.C.Types

-- Pure Haskell function
fibonacci :: Int -> Int
fibonacci 0 = 0
fibonacci 1 = 1
fibonacci n = fibonacci (n - 1) + fibonacci (n - 2)

-- Export to C
foreign export ccall hs_fibonacci :: CInt -> CInt

hs_fibonacci :: CInt -> CInt
hs_fibonacci n = fromIntegral $ fibonacci (fromIntegral n)

-- You can also export IO actions
foreign export ccall hs_print_message :: IO ()

hs_print_message :: IO ()
hs_print_message = putStrLn "Hello from Haskell!"
```

**C Program** (`main.c`):
```c
#include <stdio.h>
#include <stdlib.h>
#include "HsFFI.h"              // GHC's FFI support
#include "Fibonacci_stub.h"     // Generated by GHC

int main(int argc, char *argv[]) {
    // 1. Initialize the Haskell RTS
    hs_init(&argc, &argv);

    // 2. Call Haskell functions
    printf("Computing Fibonacci numbers:\n");
    for (int i = 0; i <= 10; i++) {
        int result = hs_fibonacci(i);
        printf("fib(%d) = %d\n", i, result);
    }

    // Call an IO action
    hs_print_message();

    // 3. Shut down the Haskell RTS
    hs_exit();

    return 0;
}
```

**Compilation**:
```bash
# 1. Compile Haskell to object file and generate stub header
ghc -c Fibonacci.hs
# Creates: Fibonacci.o, Fibonacci.hi, Fibonacci_stub.h

# 2. Compile C code
gcc -c main.c -I. -I/usr/lib/ghc-*/include

# 3. Link with GHC (not gcc!)
ghc -no-hs-main -o program main.o Fibonacci.o

# 4. Run
./program
```

**Key Points**:
- `hs_init()` starts the Haskell Runtime System
- `hs_exit()` shuts it down
- You **must** use `ghc -no-hs-main` to link
- GHC generates `*_stub.h` with C declarations

### RTS Initialization

The RTS can be configured at initialization:

```c
int main(int argc, char *argv[]) {
    // Set RTS options
    char *rts_argv[] = {
        "+RTS",
        "-N4",      // Use 4 cores
        "-H512m",   // 512MB heap
        "-RTS",
        NULL
    };
    int rts_argc = 4;

    // Initialize with options
    hs_init_with_rtsopts(&rts_argc, &rts_argv);

    // ... call Haskell functions ...

    hs_exit();
    return 0;
}
```

## Data Type Marshalling

### Basic C Types

Haskell provides type-safe wrappers for C types in `Foreign.C.Types`:

| C Type | Haskell Type | Notes |
|--------|--------------|-------|
| `char` | `CChar` | |
| `unsigned char` | `CUChar` | |
| `short` | `CShort` | |
| `int` | `CInt` | |
| `long` | `CLong` | |
| `long long` | `CLLong` | |
| `unsigned int` | `CUInt` | |
| `size_t` | `CSize` | |
| `float` | `CFloat` | |
| `double` | `CDouble` | |
| `void*` | `Ptr a` | Generic pointer |
| `char*` | `CString` | C string (null-terminated) |

### Converting Between Haskell and C Types

```haskell
import Foreign.C.Types

-- Haskell Int to C int
haskellToC :: Int -> CInt
haskellToC = fromIntegral

-- C int to Haskell Int
cToHaskell :: CInt -> Int
cToHaskell = fromIntegral

-- Haskell Double to C double
haskellDoubleToC :: Double -> CDouble
haskellDoubleToC = realToFrac

-- C double to Haskell Double
cDoubleToHaskell :: CDouble -> Double
cDoubleToHaskell = realToFrac
```

### Strings

Strings require special handling because:
- Haskell strings are `[Char]` (linked lists)
- C strings are `char*` (null-terminated arrays)

```haskell
import Foreign.C.String

-- Haskell String to C String (copies memory)
withCString :: String -> (CString -> IO a) -> IO a

-- C String to Haskell String (copies memory)
peekCString :: CString -> IO String

-- Example: calling strlen
foreign import ccall "string.h strlen"
    c_strlen :: CString -> IO CSize

getStringLength :: String -> IO Int
getStringLength str = withCString str $ \cstr -> do
    len <- c_strlen cstr
    return (fromIntegral len)

-- Example: getting a C string from a function
foreign import ccall "stdlib.h getenv"
    c_getenv :: CString -> IO CString

getEnvironmentVariable :: String -> IO (Maybe String)
getEnvironmentVariable name = withCString name $ \cname -> do
    result <- c_getenv cname
    if result == nullPtr
        then return Nothing
        else Just <$> peekCString result
```

### Arrays and Pointers

```haskell
import Foreign.Ptr
import Foreign.Marshal.Array
import Foreign.Storable

-- Allocate a C array
foreign import ccall "process_array"
    c_process_array :: Ptr CInt -> CInt -> IO ()

processArray :: [Int] -> IO ()
processArray xs = do
    let cints = map fromIntegral xs :: [CInt]
    withArray cints $ \ptr -> do
        c_process_array ptr (fromIntegral $ length xs)

-- Read from a C array
foreign import ccall "get_array"
    c_get_array :: Ptr CInt -> CInt -> IO ()

getArray :: Int -> IO [Int]
getArray n = do
    allocaArray n $ \ptr -> do
        c_get_array ptr (fromIntegral n)
        cints <- peekArray n ptr
        return (map fromIntegral cints)
```

### Structures

```c
// C structure
typedef struct {
    int x;
    int y;
    char* label;
} Point;

void print_point(Point* p);
```

```haskell
{-# LANGUAGE ForeignFunctionInterface #-}

import Foreign
import Foreign.C.Types
import Foreign.C.String

-- Define Haskell equivalent
data Point = Point
    { pointX :: Int
    , pointY :: Int
    , pointLabel :: String
    }

-- Storable instance for marshalling
instance Storable Point where
    sizeOf _ = #{size Point}
    alignment _ = #{alignment Point}

    peek ptr = do
        x <- #{peek Point, x} ptr
        y <- #{peek Point, y} ptr
        labelPtr <- #{peek Point, label} ptr
        label <- peekCString labelPtr
        return $ Point (fromIntegral (x :: CInt))
                      (fromIntegral (y :: CInt))
                      label

    poke ptr (Point x y label) = do
        #{poke Point, x} ptr (fromIntegral x :: CInt)
        #{poke Point, y} ptr (fromIntegral y :: CInt)
        withCString label $ \labelPtr ->
            #{poke Point, label} ptr labelPtr

foreign import ccall "print_point"
    c_print_point :: Ptr Point -> IO ()

printPoint :: Point -> IO ()
printPoint p = with p c_print_point
```

**Note**: The `#{}` syntax requires the `hsc2hs` preprocessor. Save as `Point.hsc` and run `hsc2hs Point.hsc` to generate `Point.hs`.

## Memory Management

### Who Owns the Memory?

| Scenario | Allocator | Deallocator |
|----------|-----------|-------------|
| Haskell calls C, temp buffer | Haskell | Haskell (automatic) |
| Haskell calls C, returned pointer | C | Haskell (must free) |
| C calls Haskell, Haskell returns data | Haskell GC | Haskell GC (automatic) |
| C calls Haskell, needs persistent data | Haskell (stable ptr) | C (via free function) |

### Temporary Allocations

```haskell
import Foreign.Marshal.Alloc
import Foreign.Storable

-- Allocate temporarily (automatic cleanup)
withAlloca :: Storable a => (Ptr a -> IO b) -> IO b

example :: IO ()
example = alloca $ \ptr -> do
    poke ptr (42 :: CInt)
    value <- peek ptr
    print value
    -- ptr is automatically freed here
```

### Manual Allocation

```haskell
import Foreign.Marshal.Alloc

-- Manual allocation (YOU must free)
manualExample :: IO ()
manualExample = do
    ptr <- malloc :: IO (Ptr CInt)
    poke ptr 42
    value <- peek ptr
    print value
    free ptr  -- Don't forget!

-- Better: use bracket for exception safety
bracketExample :: IO ()
bracketExample = bracket
    (malloc :: IO (Ptr CInt))
    free
    (\ptr -> do
        poke ptr 42
        value <- peek ptr
        print value)
```

### Stable Pointers

When C code needs to hold a reference to Haskell data:

```haskell
import Foreign.StablePtr

-- Create a stable pointer (prevents GC)
foreign export ccall hs_create_object :: IO (StablePtr MyObject)
foreign export ccall hs_use_object :: StablePtr MyObject -> IO ()
foreign export ccall hs_free_object :: StablePtr MyObject -> IO ()

hs_create_object :: IO (StablePtr MyObject)
hs_create_object = do
    obj <- createMyObject
    newStablePtr obj

hs_use_object :: StablePtr MyObject -> IO ()
hs_use_object sptr = do
    obj <- deRefStablePtr sptr
    useMyObject obj

hs_free_object :: StablePtr MyObject -> IO ()
hs_free_object = freeStablePtr
```

## Safety Levels

### `safe` vs `unsafe`

```haskell
-- safe (default): Can call back into Haskell, slower
foreign import ccall safe "slow_function"
    c_slow_safe :: CInt -> IO CInt

-- unsafe: Cannot call back into Haskell, faster
foreign import ccall unsafe "fast_function"
    c_fast_unsafe :: CInt -> IO CInt

-- interruptible: Can be interrupted by async exceptions
foreign import ccall interruptible "blocking_function"
    c_blocking :: CInt -> IO CInt
```

| Safety Level | Can call Haskell? | Can block? | Overhead |
|--------------|-------------------|------------|----------|
| `safe` | ✅ Yes | ✅ Yes | High |
| `unsafe` | ❌ No | ❌ No | Very low |
| `interruptible` | ✅ Yes | ✅ Yes | High |

### When to Use Each

**Use `unsafe` when**:
- Function is very fast (< 1μs)
- Function never calls back into Haskell
- Function never blocks
- Examples: `sin()`, `cos()`, pointer arithmetic

**Use `safe` when**:
- Function might take time
- Function might call Haskell callbacks
- You're not sure
- Examples: I/O operations, callbacks

**Use `interruptible` when**:
- Function blocks on I/O
- You want to support timeouts
- Examples: `read()`, `write()`, `accept()`

## Common Patterns

### Pattern 1: Wrapping C Libraries

```haskell
{-# LANGUAGE ForeignFunctionInterface #-}

module SQLite (
    Database,
    open,
    close,
    execute,
) where

import Foreign.C.Types
import Foreign.C.String
import Foreign.Ptr

-- Opaque pointer type
newtype Database = Database (Ptr ())

foreign import ccall "sqlite3.h sqlite3_open"
    c_sqlite3_open :: CString -> Ptr (Ptr ()) -> IO CInt

foreign import ccall "sqlite3.h sqlite3_close"
    c_sqlite3_close :: Ptr () -> IO CInt

foreign import ccall "sqlite3.h sqlite3_exec"
    c_sqlite3_exec :: Ptr () -> CString -> FunPtr a -> Ptr () -> Ptr CString -> IO CInt

-- High-level Haskell API
open :: FilePath -> IO (Maybe Database)
open path = withCString path $ \cpath ->
    alloca $ \ptrPtr -> do
        result <- c_sqlite3_open cpath ptrPtr
        if result == 0
            then Just . Database <$> peek ptrPtr
            else return Nothing

close :: Database -> IO ()
close (Database ptr) = do
    _ <- c_sqlite3_close ptr
    return ()

execute :: Database -> String -> IO Bool
execute (Database ptr) sql = withCString sql $ \csql -> do
    result <- c_sqlite3_exec ptr csql nullFunPtr nullPtr nullPtr
    return (result == 0)
```

### Pattern 2: Callbacks

```c
// C code expects a callback
typedef void (*callback_t)(int);
void register_callback(callback_t cb);
void trigger_callback(void);
```

```haskell
import Foreign.C.Types

-- Define callback type
type Callback = CInt -> IO ()

foreign import ccall "wrapper"
    mkCallback :: Callback -> IO (FunPtr Callback)

foreign import ccall "register_callback"
    c_register_callback :: FunPtr Callback -> IO ()

foreign import ccall "trigger_callback"
    c_trigger_callback :: IO ()

-- Haskell callback
myCallback :: Callback
myCallback n = putStrLn $ "Callback called with: " ++ show n

main :: IO ()
main = do
    -- Create function pointer
    fp <- mkCallback myCallback

    -- Register it
    c_register_callback fp

    -- Trigger it
    c_trigger_callback

    -- Free when done
    freeHaskellFunPtr fp
```

## Error Handling

### Pattern 1: C Functions Returning Error Codes

```c
// Returns 0 on success, -1 on error
int risky_operation(int x);
```

```haskell
foreign import ccall "risky_operation"
    c_risky_operation :: CInt -> IO CInt

riskyOperation :: Int -> IO (Either String ())
riskyOperation x = do
    result <- c_risky_operation (fromIntegral x)
    if result == 0
        then return (Right ())
        else return (Left "Operation failed")
```

### Pattern 2: C Functions Setting errno

```c
// Returns -1 and sets errno on error
int system_call(const char* path);
```

```haskell
import Foreign.C.Error
import System.Posix.Error (errno)

foreign import ccall "system_call"
    c_system_call :: CString -> IO CInt

systemCall :: FilePath -> IO (Either String Int)
systemCall path = withCString path $ \cpath -> do
    result <- c_system_call cpath
    if result == -1
        then do
            err <- getErrno
            msg <- getErrorString err
            return (Left msg)
        else return (Right (fromIntegral result))

getErrorString :: Errno -> IO String
getErrorString (Errno errno) = peekCString =<< strerror (fromIntegral errno)

foreign import ccall "string.h strerror"
    strerror :: CInt -> IO CString
```

## Best Practices

### 1. Always Use Type-Safe Wrappers

```haskell
-- ❌ Bad: Expose raw C types
c_add :: CInt -> CInt -> CInt

-- ✅ Good: Wrap with Haskell types
add :: Int -> Int -> Int
add x y = fromIntegral $ c_add (fromIntegral x) (fromIntegral y)
```

### 2. Handle Resource Cleanup

```haskell
-- ❌ Bad: Manual cleanup (easy to leak)
withFile path $ \file -> do
    handle <- c_open file
    result <- c_process handle
    c_close handle
    return result

-- ✅ Good: Use bracket
import Control.Exception

withCFile :: FilePath -> (Ptr () -> IO a) -> IO a
withCFile path action = bracket
    (withCString path c_open)
    c_close
    action
```

### 3. Check Return Values

```haskell
-- ❌ Bad: Ignore errors
doThing :: IO ()
doThing = do
    _ <- c_risky_operation
    return ()

-- ✅ Good: Handle errors
doThing :: IO (Either String ())
doThing = do
    result <- c_risky_operation
    if result == 0
        then return (Right ())
        else return (Left "Operation failed")
```

### 4. Use `unsafe` Judiciously

```haskell
-- ❌ Bad: Unsafe for I/O
foreign import ccall unsafe "unistd.h read"
    c_read :: CInt -> Ptr () -> CSize -> IO CSsize

-- ✅ Good: Safe for I/O
foreign import ccall safe "unistd.h read"
    c_read :: CInt -> Ptr () -> CSize -> IO CSsize
```

## Troubleshooting

### Problem: Undefined Reference Errors

```
undefined reference to `my_c_function'
```

**Solution**: Make sure you're linking the C object file or library:

```bash
ghc MyProgram.hs my_c_code.o
# or
ghc MyProgram.hs -lmylib
```

### Problem: Segmentation Fault

Common causes:
1. **Null pointer dereference**
2. **Memory not allocated**
3. **Calling unsafe FFI function that blocks**
4. **Not calling `hs_init()` before using Haskell from C**

Debug with:
```bash
ghc -debug MyProgram.hs
./MyProgram +RTS -xc  # Show stack trace on crash
```

### Problem: Memory Leaks

**Check**:
- Are you `free`ing manually allocated memory?
- Are you `freeStablePtr`ing stable pointers?
- Are you `freeHaskellFunPtr`ing callback function pointers?

Use memory profiling:
```bash
ghc -prof -fprof-auto MyProgram.hs
./MyProgram +RTS -hc -p
```

### Problem: Mysterious Crashes with Callbacks

**Cause**: Callback function pointer was garbage collected.

**Solution**: Keep the FunPtr alive:
```haskell
-- ❌ Bad
registerCallback :: IO ()
registerCallback = do
    fp <- mkCallback myCallback
    c_register fp
    -- fp goes out of scope and might be GC'd!

-- ✅ Good
registerCallback :: IO (FunPtr Callback)
registerCallback = do
    fp <- mkCallback myCallback
    c_register fp
    return fp  -- Caller must hold onto this!
```
